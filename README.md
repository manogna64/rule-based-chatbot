# 🤖 Buddy - Rule-Based Chatbot

A simple and interactive **rule-based chatbot built with Python** as part of my **CODSOFT Artificial Intelligence Internship**.

Buddy uses predefined rules and pattern matching to respond to user inputs and provide basic conversational functionality.

## 🚀 Features

- 👋 Responds to greetings
- 🧑 Remembers and uses the user's name
- 🕐 Provides the current time
- 📅 Provides the current date
- 😂 Tells jokes
- 🧮 Performs basic mathematical calculations
- ➗ Handles division-by-zero errors
- ❓ Provides a help command
- 💬 Handles unknown inputs with a fallback response
- 👋 Provides a personalized goodbye message

## 🛠️ Technologies Used

- **Python**
- Regular Expressions
- Date & Time Handling
- Rule-Based Logic
- Conditional Statements

## 💬 Example Interaction

```text
==================================================
 Buddy - Rule-Based Chatbot
 Type 'help' for options, 'bye' to quit
==================================================

Buddy: Hi! I'm Buddy. How can I help you?

You: Hello
Buddy: Hey! I'm Buddy. What's your name?
```
